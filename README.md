# ControlPanel
一些面板，还没想好


一个单文件 HTML 实现的宇宙战舰舰长控制面板 demo，科幻感克制、信息密度高，
风格参考 **SpaceX Dragon 座舱 UI** 与 **《流浪地球2》MOSS 终端界面**（深色底、细线框、
双语标签、数据优先，不做花哨的霓虹渐变堆砌）。

## 运行方式

直接双击打开 [`captain-console.html`](./captain-console.html) 即可。

> ⚠️ 需要联网：页面通过 CDN 加载 **Vue 3** 与 Google Fonts（西文数字用 Share Tech Mono，
> 中文用 Noto Sans SC）。断网时会显示降级提示，其余功能不受影响（字体回退到系统字体）。

## 三大板块

| 板块 | 内容 |
| --- | --- |
| **01 航行 NAVIGATION** | Canvas 星海航行动画（推杆越快星流越快）、航路折线与航点、航速/航向/燃料/姿态遥测、推进功率滑杆、点击航点切换目标 |
| **02 命令 COMMAND** | 任务阶段推进、舰船 SVG 示意（引擎火焰随推力变化、跃迁光环）、引擎点火/跃迁/护盾/静默指令、紧急警报、AI 副官打字机播报、滚动指挥日志 |
| **03 武器 WEAPONS** | 战术雷达（扫描扇面 + 目标光点 + 开火扩散波）、目标锁定进度、四种武器系统（充能/弹药/齐射） |

## 技术栈

- **Vue 3**（CDN 全局构建）：响应式状态与界面绑定，单文件即可运行
- **Canvas 2D**：星海航行、战术雷达两套 requestAnimationFrame 渲染循环
- **CSS 动画**：扫描线/暗角微纹理、航路虚线流动、警报脉冲、面板聚焦高亮
- **WebAudio API**：按钮/充能/开火音效（顶栏 ♪ 可开关）
- 键盘快捷键：`1` 航行 · `2` 命令 · `3` 武器 · `空格` 开火
