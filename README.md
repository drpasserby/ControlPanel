# ControlPanel
一些面板，还没想好


一个单文件 HTML 实现的宇宙战舰舰长控制面板 demo，科幻感克制、信息密度高，
风格参考 **SpaceX Dragon 座舱 UI** 与 **《流浪地球2》MOSS 终端界面**（深色底、细线框、
双语标签、数据优先，不做花哨的霓虹渐变堆砌）。

## 运行方式

直接双击打开 [`captain-console.html`](./captain-console.html) 即可。

**联网 / 离线两手准备**：

- **Vue 3**：优先从 CDN（unpkg）加载，失败或 4 秒超时后自动回退到本地
  [`libs/vue.global.prod.js`](./libs/vue.global.prod.js)（v3.3.11，相对路径）。
- **字体**：优先 Google Fonts CDN（Share Tech Mono + Noto Sans SC）；
  获取不到时注入本地 `fonts/` 目录的 woff2（相对路径）；本地也没有时落到系统字体
  （Windows 下为 Consolas + Microsoft YaHei），界面依然完整可读。
  > 如需离线字体，把对应的 woff2 放进 `fonts/` 并按下述命名即可：
  > `share-tech-mono.woff2`、`noto-sans-sc-300.woff2`、`noto-sans-sc-400.woff2`、`noto-sans-sc-500.woff2`

## 星舰命名

首次打开会弹出「星舰登记」界面，由舰长自己填写舰名（存于浏览器 localStorage，
键名 `captainConsole.shipName`）；之后再次打开会直接读取舰名、跳过命名进入开机自检。
顶栏右上角 **✎** 按钮可随时修改舰名。

## 三大板块

| 板块 | 内容 |
| --- | --- |
| **01 航行 NAVIGATION** | Canvas 星海航行动画（推杆越快星流越快）、航路折线与航点、航速/航向/燃料/姿态遥测、推进功率滑杆、点击航点切换目标 |
| **02 命令 COMMAND** | 战备等级切换（巡航/戒备/作战）、舰船 SVG 示意（引擎火焰随推力变化、护盾光环）、跃迁引擎（90 秒充能进度 → 执行跃迁，星海流光 + 闪光特效）、引擎点火/护盾/电子静默指令（静默期 AI 副官与随机事件停播）、紧急警报、AI 副官打字机播报、滚动指挥日志 |
| **03 武器 WEAPONS** | 战术雷达（扫描扇面 + 目标光点 + 开火扩散波）、目标锁定（未锁定无法开火）、四种武器系统（充能/弹药）、持续开火（单武器自动充能射击）、智能作战（全武器自动接战） |

## 舰桥三域结构

顶栏中央是**一级域切换**（作战 / 舰船 / 情报），进入多子系统的域后，主区上方出现**二级子系统标签**。
顶栏、底栏、指挥日志跨域常驻。

| 一级域 | 二级子系统 |
| --- | --- |
| **作战 OPS** | **航行**（星海示意 + 星图弹层：15 个坐标含母港/前哨/跃迁门/任务目标/禁区，部分可航行可设目的地）· **命令** · **武器**（无二级标签，三栏直显） |
| **舰船 SHIP** | 动力（能量分配滑杆/紧急模式）· 损管（舰体剖面/抢修小组）· 物资（库存/补给/日志 + **维生子板块** O₂/CO₂/温湿度 + 应急协议）· 医疗（健康指数/资源/体检） |
| **情报 INTEL** | 通信（频道/消息/破译/信标）· 科研（观测/扫描/异常分析/档案） |

键盘：`Q/E` 在域内切换子系统 · `1/2/3` 切换当前子系统内面板 · `空格`（作战）开火

## 技术栈

- **Vue 3**：响应式状态与界面绑定（CDN 优先，本地 `libs/` 回退）
- **Canvas 2D**：星海航行、战术雷达两套 requestAnimationFrame 渲染循环
- **CSS 动画**：扫描线/暗角微纹理、航路虚线流动、警报脉冲、面板聚焦高亮、飞船状态动效
- **WebAudio API**：按钮/充能/开火音效（顶栏 ♪ 可开关）
- **localStorage**：舰名持久化
- 键盘快捷键：`Q/E` 切换域内子系统 · `1/2/3` 切换子系统内面板 · `空格`（作战）开火
